```

      ?
      ?
Display Question 1
      ?
      ?? Student selects answer
      ?  ?? Progress updates
      ?
      ?? Student clicks [NEXT ?]
      ?  ?? _currentQuestionIndex++
      ?     Display Question 2
      ?
      ?? Student clicks [? PREVIOUS]
      ?  ?? _currentQuestionIndex--
      ?     Display Question 1 again
      ?     (Previous answer still selected)
      ?
      ?? (Navigate through Q2...Q9)
      ?
      ?
Display Question 10 (LAST)
      ?
      ?? [? PREVIOUS] remains enabled
      ?? [? NEXT] is now DISABLED
      ?
      ?? If all answered
      ?  ?? [SUBMIT] becomes ENABLED
      ?
      ?
Student clicks [SUBMIT]
      ?
      ?
Calculate Scores
      ?
      ?
Display ThankYouWindow
      ?
      ?
END
```

## Responsive Breakpoints

```
Desktop (1000px+):
?? Full layout as shown
?? 45x45px buttons
?? Question card width: 600px max
?? Spacious padding: 40px

Tablet (600px - 1000px):
?? Slightly reduced padding
?? Question card width: 90% of screen
?? 45x45px buttons (still large for touch)
?? Language toggle might wrap

Mobile (< 600px):
?? Minimal padding
?? Question card: full width minus margins
?? 45x45px buttons (touch-friendly)
?? Text might be smaller (but still readable)
?? Options stack vertically
```
