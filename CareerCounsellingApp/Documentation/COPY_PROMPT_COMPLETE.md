```
  ?? CopyPromptCommand (ICommand)
  ?? CopyPromptToClipboardAsync() method
  ?? _promptBuilder field
```

### Data Flow
```
Assessment Report Data
  ?
GeminiPromptBuilder.Build(report)
  ?
CurrentPrompt = full prompt text
  ?
User clicks button
  ?
CopyPromptCommand executed
  ?
CopyPromptToClipboardAsync()
  ?
System.Windows.Forms.Clipboard.SetText()
  ?
IsPromptCopied = true (shows "? Copied!")
  ?
Wait 2 seconds
  ?
IsPromptCopied = false (reverts button text)
```
