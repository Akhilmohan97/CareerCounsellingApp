## Color Combinations

### For Light Backgrounds
```
Background: #FFFFFF or #F7FAFC
Text Color: #1A202C (high contrast)
Accents: #2563EB (primary)
Borders: #E2E8F0 (subtle)
```

### For Dark Backgrounds
```
Background: #1E3A5C or #152847
Text Color: #FFFFFF (white)
Accents: #3B82F6 (lighter blue)
Secondary: #A0AEC0 (light gray)
```

### For Backgrounds
```
Primary: #F0F4F9 (soft blue)
Secondary: #FFFFFF (pure white)
Accent: #EFF6FF (very light blue)
```

## State Indicators

### Button States
```
Enabled:  Full color, cursor: pointer
Disabled: 50% opacity, cursor: default
Hover:    Darker color, slight scale up feeling
Pressed:  Even darker, held feeling
Focus:    Border highlight, indication ring
```

### Input States
```
Empty:      Gray placeholder
Filled:     Dark text
Focus:      Blue border, active state
Error:      Red border, #EF4444 indicator
Success:    Green border, #10B981 indicator
Disabled:   50% opacity
```
